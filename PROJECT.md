Initiate a new research project according to the following structure:
```
- README.md # for clarification and documentations
- docs/ # for storing useful literature and docs
  - APA # copying FIGURE.MD, LATEX-APA.md, STATISTICS.md, and TABLE.md to this folder
  - literature # if we have any literature (in pdf or md), move to here
- script
- replication
- data
  - raw
  - cleaned
  - process
  - result
- output
  - fig
  - tex
- paper # for latex paper project using apa7 cls
- sync_results.sh # for syncing output to paper/fig and paper/tex
```
